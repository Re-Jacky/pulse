UI Layer

Data Layer
SystemMonitor (ObservableObject)
CPUMonitor — host_processor_info
MemoryMonitor — host_statistics64
GPUMonitor — IOKit registry
Data flow: SystemMonitor polls on a 2-second Timer. Each sub-monitor reads directly from macOS APIs (no external dependencies). @Published properties propagate changes to SwiftUI automatically. No persistence needed — live data only.
